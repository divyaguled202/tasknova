## ✨ Features

- 🔐 **Authentication**
  - Login & Signup system
  - Persistent login using LocalStorage

- 📊 **Smart Dashboard**
  - 📅 Today Tasks  
  - 📆 This Week Tasks  
  - ✅ Completed Tasks  
  - 📁 All Tasks  

- 📝 **Task Management**
  - Add tasks
  - Mark as completed
  - Delete tasks
  - Real-time UI updates

- 🎨 **Modern UI/UX**
  - Glassmorphism design 💎  
  - Neon glow effects ✨  
  - Smooth animations (Framer Motion)  
  - Fully responsive design 📱  

- 🌌 **Animated Background**
  - Gradient animation  
  - Floating particles  
  - Optional 3D effects
